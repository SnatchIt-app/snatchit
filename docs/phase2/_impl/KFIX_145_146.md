## Root cause

Migration `102_credential_signing_context_and_saleable.sql` added four
SALEABLE gates (`org_not_saleable`, `connect_not_ready`, `signing_not_ready`,
`fee_policy_unset`, in that order) to `catalog.publish_event`'s `on_sale`
transition, evaluated after the pre-existing `empty_inventory` check. Both
fixtures published events to `on_sale` with none of those four prerequisites
in place, so both now abort mid-file.

same ladder, and its refusal tests — F0 `payout_not_ready` (org unbound),
