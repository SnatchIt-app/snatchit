## What this does and does not establish

- **Does:** the two migrations replay together from empty, in the intended order, with no conflict in the
  merge and no modification to any existing migration; and the resulting object census is the one CI will
  assert.
- **Does not:** substitute for CI. A CI run on a pushed temporary integration branch is still what makes
  post-merge CI not the first *CI* test of the combination. That push is a separate action.
- **Does not** establish anything about production. No production read was made.

## Reuse conditions

This evidence is reusable **only while all three inputs are unchanged**: gate `037092f0`, #94 head
