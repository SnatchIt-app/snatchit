# Ticket Transfer Method Research — Official Sources

**Date:** 2026-06-12 · **Purpose:** ground Snatch It's platform options and in-app transfer instructions in official documentation only. Anything not confirmed by an official page is marked **UNVERIFIED** and is NOT implemented in the app. Sources cited inline per platform.

Legend: ✅ confirmed from official source · ⚠️ UNVERIFIED (not used in app copy)

---

## 1. Ticketmaster (includes Live Nation events)

- **Transfer:** ✅ Yes, free P2P transfer; recipient gets a NEW barcode and the sender's is invalidated. Live Nation events use Ticketmaster accounts.
- **Methods:** ✅ email or phone/text (app or mobile browser). Recipient needs a Ticketmaster account.
- **Restrictions:** ✅ event/artist can disable transfer (no Transfer button = not eligible); merch/VIP elements/insurance not transferable; sender verifies via one-time SMS code. ⚠️ A "72h before event" availability window appears in Live Nation help search results but exact text unconfirmed.
- **Seller steps:** ✅ Sign in → My Tickets → select order → Transfer → one-time code → select tickets → Transfer To → enter recipient email/phone → confirm/send.
- **Buyer steps:** ✅ Tap Accept Tickets link in email/text → sign in or create account (same email the tickets were sent to) → tickets appear in My Tickets. Sender can cancel before acceptance.
- **Screenshots:** ✅ **NOT valid.** SafeTix rotating barcode refreshes every ~15s; official: "Screenshots won't get you in."
- Sources: https://help.ticketmaster.com/hc/en-us/articles/9786975926673-How-does-Ticket-Transfer-work · https://help.ticketmaster.com/hc/en-us/articles/26584309038353-Why-do-my-tickets-have-a-moving-barcode · https://help.livenation.com/hc/en-us/articles/9982212303505

## 2. AXS

- **Transfer:** ✅ Yes for AXS Mobile ID tickets ("Transfer"); e-tickets use "Share" (printable PDF by email). Event-dependent.
- **Methods:** ✅ recipient first/last name + **email or phone**; sender passes one-time passcode.
- **Restrictions:** ✅ add-ons/VIP/insurance typically not transferable; some events disable transfer.
- **Seller steps:** ✅ AXS app → ticket icon → event → Transfer → select tickets → recipient name + email/phone → review → Transfer Tickets.
- **Buyer steps:** ✅ open email/text link → create/sign in to AXS account (+ app) → tickets land in account.
- **Screenshots:** ⚠️ no explicit official ban found; Mobile ID is in-app, shared e-tickets are explicitly printable PDFs. App copy says "present in AXS app" without claiming a ban.
- Sources: https://support.axs.com/hc/en-us/articles/201086744-How-do-I-transfer-AXS-Mobile-ID · https://support.axs.com/hc/en-us/articles/360031482794-What-is-Transfer-Share

## 3. SeatGeek  *(Miami: Florida Panthers / Amerant Bank Arena partner)*

- **Transfer:** ✅ Yes, SeatGeek account → SeatGeek account (not for tickets delivered via Ticketmaster/AXS/league apps — transfer there instead).
- **Methods:** ✅ name, username, **email, or phone**. Recipient account created on accept if needed.
- **Restrictions:** ✅ one recipient per transfer; sender email+phone must be verified; cancel only before acceptance.
- **Seller steps:** ✅ Tickets → select event → Transfer → select tickets → recipient info → Transfer now.
- **Buyer steps:** ✅ open email/text/push → sign in or create account (same email) → Tickets → accept.
- **Screenshots:** ✅ prohibited for rotating-barcode tickets (e.g. NFL ~15s refresh); SeatGeek does not allow uploading screenshots of changing-barcode tickets. Panthers/Amerant: official FAQ — "Screenshots of tickets will not be accepted."
- Sources: https://support.seatgeek.com/hc/en-us/articles/360007200234 · https://support.seatgeek.com/hc/en-us/articles/12989813265043 · https://seatgeek.com/blog/can-you-screenshot-seatgeek-tickets · https://www.nhl.com/panthers/tickets/mobileticketing · https://www.amerantbankarena.com/events/ticket-information

## 4. Dice (dice.fm)  *(Miami: Club Space, The Ground, Factory Town, Miami Beach Bandshell)*

- **Transfer:** ✅ Yes — "Send ticket to a friend," **app-only, recipient chosen from your phone contacts** (DICE accounts are phone-number-based). **No email or link transfer.**
- **Restrictions:** ✅ organizer can disable; must transfer before the deadline shown on the ticket (usually a few hours pre-event); impossible after QR activation; selling only via DICE Wait List; DICE warns tickets resold on third-party sites may be revoked.
- **Seller steps:** ✅ DICE app → ticket icon → event → "Send ticket to a friend" → pick phone contact → choose qty → Send.
- **Buyer steps:** ✅ have a DICE account registered to the phone number the seller has in contacts; ticket appears in your DICE app.
- **Screenshots:** ✅ **NOT valid** — official: "Please do not screenshot the QR code, as your ticket may not be valid for entry." QR activates only on event day.
- Sources: https://dice.fm/help/article?id=4409669378449 · https://dice.fm/help/article?id=19413725197713 · https://dice.fm/help/article?id=18201556722961
- **⚠️ App impact:** previous in-app DICE copy described an email transfer — **incorrect**, fixed to phone-contact flow.

## 5. Eventbrite

- **Transfer:** ✅ **No account-to-account transfer.** Official: "It is not possible to transfer a ticket from one account to another." Mechanism = original purchaser **edits the order's attendee name + email** (only if organizer allows), and the new person claims the ticket.
- **Seller steps:** ✅ Account → Tickets → select order → Edit → change name + email → save. No Edit option = organizer disabled changes.
- **Buyer steps:** ✅ receive Eventbrite "claim tickets" email → claim → ticket (PDF/QR) under your name/email.
- **Screenshots:** ✅ static QR; Eventbrite support states printouts or screenshots are scannable at the door. Organizer may check ID — name should match.
- Sources: https://www.eventbrite.com/help/en-us/articles/431834/how-to-transfer-tickets-to-someone-else/ · https://www.eventbrite.com/help/en-us/articles/441118/ · https://www.eventbrite.com/support/articles/en_US/Q_A/do-i-need-to-print-my-ticket
- **⚠️ App impact:** previous in-app Eventbrite copy described a "Transfer" button — **incorrect**, fixed to the edit-order-info flow.

## 6. Posh (posh.vip)

- **Transfer:** ✅ Yes — **app-only, by recipient phone number** (Posh accounts are phone-based). New order created for recipient; original QR scans as "Canceled" after transfer.
- **Restrictions:** ✅ organizer can disable per ticket type; transferred tickets non-refundable; payment-plan, comp, and approval-required tickets not transferable; no website transfers.
- **Seller steps:** ✅ Posh app → order → Transfer Tickets → select → recipient phone number → confirm. Cancelable while pending.
- **Buyer steps:** ✅ text/app notification → sign in (account on that phone number) → accept.
- **Screenshots:** ✅ a screenshot taken before transfer is dead (QR canceled); no explicit ban otherwise (⚠️).
- Sources: https://support.posh.vip/en/articles/10723763-how-to-transfer-tickets · https://support.posh.vip/en/articles/10723736-enabling-ticket-transfers

## 7. Tixr  *(Miami: LIV, Story, E11EVEN, Daer, M2, Oasis Wynwood)*

- **Transfer:** ✅ Yes — free, **by recipient email**, web or app; pending transfers cancelable before acceptance. Selling must go through Tixr's official resale.
- **Restrictions:** ✅ organizer-controlled (no Transfer button = not offered); payment plans must be fully paid; NFC/rotating-QR ticket types deliverable only through Tixr (no export).
- **Seller steps:** ✅ Tixr.com or app → Wallet → event card → Transfer → select tickets → recipient email → Complete Transfer.
- **Buyer steps:** ✅ open "Ticket Transfer" email → Accept → log in/create account with **the same email** → Accept Transfer.
- **Screenshots:** ✅ rotating-QR/NFC types cannot be screenshotted (app-delivered); standard types unstated (⚠️).
- Sources: https://support.tixr.com/transferring-tickets · https://fansupport.tixr.com/en/articles/11395549-how-to-accept-ticket-transfers · https://support.tixr.com/fan-transfers-faq

## 8. Fever (feverup.com)

- **Transfer:** ✅ Yes — **shareable link** from the Fever app (when the experience allows it).
- **Seller steps:** ✅ Fever app → Tickets → select → Transfer tickets → Transfer via link → choose qty → Share link.
- **Buyer steps:** ✅ open link → install Fever app → log in/sign up → tickets appear in Tickets; recipient becomes owner.
- **Restrictions:** ✅ option hidden if not allowed; only before the experience.
- **Screenshots:** ⚠️ no official statement.
- Source: https://support.feverup.com/hc/en-us/articles/360000999643-How-do-I-transfer-a-ticket

## 9. See Tickets US

- **Transfer:** ✅ Yes — "ticket share" tool, account-to-account, original purchaser only; shared tickets cannot be re-shared by the recipient; sharer can reclaim. Digital tickets typically available ~1 week pre-event.
- **Screenshots:** ⚠️ unstated. **Resale marketplace:** appears not offered (⚠️); See Tickets warns obligations run to the original purchaser only.
- Sources: https://support.seetickets.us/hc/en-us/articles/220446268 · https://support.seetickets.us/hc/en-us/articles/220447288 · https://support.seetickets.us/hc/en-us/articles/220447128

## 10. Universe (Ticketmaster-owned)

- **Transfer:** ✅ Yes — full ownership transfer **by email** from the Universe account.
- **Seller steps:** ✅ ticket → More → Transfer Ticket → recipient first/last name + email → Transfer.
- **Buyer steps:** ✅ "Confirm Your Ticket Transfer" email → authenticate/accept.
- **Restrictions:** ✅ one ticket at a time; **irreversible**; order becomes non-refundable after transfer; organizer can disable.
- **Screenshots:** ⚠️ unstated.
- Sources: https://support.universe.com/hc/en-us/articles/360002614651-Transfer-your-ticket · https://support.universe.com/hc/en-us/articles/360002125951

## 11. Shotgun (shotgun.live)

- **Transfer:** ✅ Yes — app-only "Send as a gift" via **shareable link**; plus official private/public resale. Organizers can block.
- **Seller steps:** ✅ app → My tickets → ticket QR → Transfer → Send as a gift → share link. Cancelable before acceptance only.
- **Buyer steps:** ✅ open link → accept in Shotgun app (account required).
- **Screenshots:** ⚠️ QR state changes live in-app (pending/transferred); no explicit ban article.
- Sources: https://support.shotgun.live/hc/en-us/articles/16488243507218 · https://support.shotgun.live/hc/en-us/articles/16484166118290

## 12. MLB Ballpark app  *(Miami: Marlins / loanDepot park)*

- **Transfer:** ✅ Yes — "Ticket Forwarding" in the MLB Ballpark app (free MLB account required).
- **Methods:** ✅ email, phone contacts, or unique **Share Link** (first to accept gets the ticket).
- **Restrictions:** ✅ eligibility per ticket; window = purchase until 2h after first pitch if unscanned; sender can recall any time **before scan, even after acceptance**; re-forwarding allowed.
- **Seller steps:** ✅ Tickets tab → game → Forward Ticket → select → Contacts/Email/Share Link → Send.
- **Buyer steps:** ✅ tap Accept in email/link → install Ballpark app if prompted → tickets in Tickets tab. Apple Wallet supported; Google Pay not.
- **Screenshots:** ⚠️ no explicit ban found; barcode must be presented in Ballpark app or Apple Wallet.
- Sources: https://www.mlb.com/marlins/tickets/mobile/faq · https://www.mlb.com/marlins/tickets/mobile

## 13. StubHub  *(as a source platform)*

- **Delivery:** ✅ mobile-transfer via external account (Ticketmaster/AXS/DICE), app barcodes, PDF/instant download.
- **Re-transfer:** ✅ conditionally — app tickets re-transferable only if "Manage Transfers" button present; externally delivered tickets re-transfer inside that platform per its rules.
- **Screenshots:** ✅ official — static barcode: high-quality screenshot acceptable; **rotating barcode: screenshots NOT accepted**.
- Sources: https://support.stubhub.com/articles/61000307245 · https://support.stubhub.com/articles/61000276760 · https://support.stubhub.com/en/support/solutions/articles/61000276313

## 14. Vivid Seats  *(as a source platform)*

- **Delivery:** ✅ mobile e-tickets, PDF/instant download, electronic transfer (via Ticketmaster etc.), AXS Mobile ID, shipping.
- **Re-transfer:** ✅ "in most cases" for Electronic Transfer tickets, from the external account where accepted. PDFs forwardable (static barcode, first scan wins).
- **Screenshots:** ⚠️ no official article; rotating-barcode deliveries inherit the vendor's rules.
- Sources: https://support.vividseats.com/support/solutions/articles/1000210347 · https://support.vividseats.com/support/solutions/articles/11000005324

## 15. Gametime  *(as a source platform)*

- **Delivery:** ✅ in-app barcodes (most common) or external delivery via Ticketmaster/AXS/SeatGeek/MLB Ballpark/Paciolan.
- **Re-transfer:** ✅ in-app share to friends via text/email within Gametime; external deliveries re-transfer per that platform. ⚠️ exporting in-app Gametime barcodes to Ticketmaster/AXS not officially documented (treated as not possible).
- **Screenshots:** ⚠️ unstated for static in-app barcodes; rotating-barcode events are forced to external delivery.
- Sources: https://support.gametime.co/en_us/ticket-delivery-via-other-platforms-information-ByN2ZEV6q · https://support.gametime.co/en_us/reselling-tickets-delivered-via-other-platform-Hk0xzo62q

## Decisions implemented in the app (research → product)

1. **Platform list expanded** from 6 → 16: existing `dice, eventbrite, posh, axs, ticketmaster, other` + new `seatgeek, tixr, fever, shotgun, universe, see_tickets, mlb_ballpark, stubhub, vivid_seats, gametime`. Front Gate/Ultra intentionally excluded (insufficient official confirmation).
2. **Corrected existing copy:** DICE = phone-contact in-app transfer (not email); Eventbrite = edit-order name/email claim flow (not account transfer).
3. **Screenshot warnings** added only where officially documented (Ticketmaster/SafeTix, DICE, SeatGeek/Panthers, StubHub-rotating, Tixr rotating/NFC, Hard Rock Live). Platforms with no official statement carry neutral "present in the official app" guidance — no invented claims.
4. **Delivery-contact logic:** platforms confirmed phone-based (DICE, Posh) prompt for buyer phone; email-based (Tixr, Universe, Ticketmaster, AXS, SeatGeek, Eventbrite-claim, MLB) prompt email-first. Link-based (Fever, Shotgun, MLB share-link) instruct via link sharing.
