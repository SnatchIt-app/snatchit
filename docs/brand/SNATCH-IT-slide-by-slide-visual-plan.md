# SNATCH IT — Slide-by-Slide Visual Upgrade Plan

**Goal:** increase emotional impact through photography + atmosphere only.
**Guardrails:** no redesign · no color change · no type change · no layout change · no copy change. Visual direction only.

### The grade (one look, every image)
**"A24 Low-Key Film."** Crushed blacks, desaturated color, one warm/amber or single red light allowed to glow, subtle film grain, faces obscured. Cinematic restraint — *anticipation, not partying.*

### The four mental filters for every image
- A24 film still, **not** nightclub flyer.
- **Anticipation**, not the party itself.
- **Access**, not luxury.
- **Sold out**, not VIP.

### Hard avoids (recurring)
Bottle service · influencers · yachts · club promoters · stock-smile photography · EDM/laser/pyro flyer aesthetics · velvet-rope VIP clichés · purple-green club lighting · real venue/artist logos or recognizable faces · literal chat screenshots.

### Placement vocabulary
- **Full bleed** — image fills the slide, type floats over a darkened frame.
- **Hero image** — large dominant image sharing the slide with type (not edge-to-edge).
- **Inset image** — a contained, framed image inside the layout (like the existing phone/founder slots).
- **Background texture** — very low-opacity image/grain behind type; data stays 100% legible.
- **Clean** — no imagery; black canvas + red accent + type.
