What changed, and why:
  1. Status first. The buyer's question is "where are my tickets?", answered in the first block instead of after the form and the instructions.
  2. The release warning is on the button, not four blocks above it. A consequence stated next to the tap is a consequence read.
  3. The proof is a real row, with when it arrived — the current viewer is a rounded well with no metadata.
  4. Success stays on the screen (state block + the existing haptic) instead of a system alert to dismiss.
  5. Never "Unknown": with no display name, the row says "the seller" — the role is always known.
  6. Pull-to-refresh added, because this is the one screen whose content arrives from someone else.

What changed, and why:
  1. Offline is named, with the two facts a buyer needs: the card was not charged, and the hold is still theirs (both already known to the screen — the hold countdown exists today).
  2. The button stops lying. Disabled while unreachable, with its reason, instead of inviting a tap that cannot succeed.
  3. Prices use textStyle('price') — tabular figures, real 700 face, on-scale — so the column aligns and no synthetic bold is requested.
  4. Everything else is untouched: layout, copy, hold countdown, Stripe line, haptic success. This screen is the app's best-instrumented; the audit does not rebuild it.
