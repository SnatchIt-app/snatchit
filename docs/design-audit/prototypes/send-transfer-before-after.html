What changed, and why:
  1. One state, one voice. The blocking condition is stated once, and the button carries its own reason instead of a separate red line. Disabled buttons that explain themselves need no second warning.
  2. Expiry tells the truth. The copy matches what the code does: sending still works until the sweep closes the transfer, and the consequence of closure is named.
  3. The task is above the fold. Proof and CTA come first; the instructions collapse to one row that keeps its useful metadata (steps, time, cautions) so nothing is hidden, only folded.
  4. The attestation moved onto the action. On an enabled button the sub-line reads "I transferred these tickets", so the claim is made by the tap, not by grey text near it.
  5. Approved geometry. Square corners, red-tinted hairlines, Oswald for the state title — the legacy panel's rounded cards and neutral borders are gone.
